# Шың 140

ҰБТ форматындағы онлайн сынақ және жеке дайындық траекториясы жүйесі.

Автор: Юлдашев Кадыржан, математика пәні мұғалімі, Ө.Жәнібеков атындағы ЖББМ, Сауран ауданы.

## «Бағдаршам» ережесі

- Қызыл: 50%-дан төмен — бірінші кезекте пысықталады.
- Сары: 50–79% — бекіту және жаттығу.
- Жасыл: 80% және жоғары — ұмытпау үшін қайталау.

## «Жартысы — шекара» ережесі

Тақырыптық тестте сұрақтардың жартысынан азы дұрыс болса, жауаптар көрсетілмейді және тест қайта тапсырылады. Жартысы немесе одан көбі дұрыс болса, қатемен жұмыс ашылады.

## Қауіпсіздік

Траектория құрастырушы деректерді ешқайда жібермейді: бәрі оқушының не мұғалімнің браузерінде есептеледі. Оқушының аты-жөнінің орнына код қолданылады.
